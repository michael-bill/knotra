# Hosted help center: HarborHelp

Fictional sample offer for this exercise. These are not live vendor prices or independently verified
claims.

Monthly cost: 139 USD. Estimated setup time: 2 working days. Design control: theme customization
only (control = theme). Support: managed vendor support (support = managed).

The offer includes search, hosting, backups, and a custom domain. Articles can be exported as CSV;
redirects and theme settings cannot be exported. The plan includes 2 editors and up to 100 published
articles. The vendor states that support replies within one working day, but provides no uptime
guarantee. No mobile usability test results are included in the offer.

These costs exclude sales tax and the team's time writing articles.
