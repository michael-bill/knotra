# Existing CMS: GrovePress knowledge section

Fictional sample offer for this exercise. These are not live vendor prices or independently verified
claims.

Monthly cost: 59 USD. Estimated setup time: 7 working days. Design control: full templates and
source code (control = full). Support: community forums, with no response commitment (support =
community).

The offer extends the team's existing website with search and a help-article template. Articles can
be exported as Markdown, including image references. The team must manage plugin upgrades and test
backups once a month. An engineer estimates two maintenance hours per month; this is not a measured
result. There are no limits on editor accounts in the offer. The search plugin's accessibility has
not been tested.

These costs exclude sales tax and the team's time writing articles or maintaining the CMS.
