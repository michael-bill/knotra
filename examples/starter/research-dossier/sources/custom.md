# Custom documentation site: AtlasDocs build

Fictional sample offer for this exercise. These are not live vendor prices or independently verified
claims.

Monthly cost: 29 USD. Estimated setup time: 18 working days. Design control: full source code and
templates (control = full). Support: the internal engineering team (support = internal).

The proposal uses static Markdown pages, a custom theme, and a hosted search index. All content and
theme source files are versioned in the team's repository. The team must build preview publishing
and train nontechnical editors. There is no included support service or response-time commitment.
The delivery estimate assumes one engineer is available throughout the build. No prototype or
customer usability results are included in the proposal.

These costs exclude sales tax, engineering labor, and the team's time writing articles.
